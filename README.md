8 assignments for Mobile Application Development have been added to this repo. Each branch represents one assignment.

Assignments:

1. Hello World App: Create a simple app that displays "Hello World" on the screen.
2. To-Do List: Create a to-do list app where users can add, edit, and delete tasks.
3. Counter App: Build a basic counter app that increases and decreases a number when buttons are pressed.
4. Simple Calculator: Develop a basic calculator that performs addition, subtraction, multiplication, and division.
5. Quiz App: Develop a quiz application with multiple-choice questions and score tracking.
6. Recipe App: Build a recipe app where users can browse, search, and save recipes.
7. Expense Tracker: Create an expense tracker app to manage and track daily expenses.
8. Firebase Authentication: Create an app that includes user authentication with Firebase (email/password, Google sign-in).
